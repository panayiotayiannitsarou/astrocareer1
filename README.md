# Επαγγελματικός Προσανατολισμός

Αυτόνομη εφαρμογή Streamlit μόνο για την υπηρεσία επαγγελματικού προσανατολισμού παιδιού ή εφήβου και επαγγελματικού αναπροσανατολισμού ενηλίκου.

## Τι περιλαμβάνει

- Ανάγνωση Astrodienst Natal Chart Data Sheet PDF.
- Μαθηματικά ελεγμένες θέσεις, Οίκους και όψεις.
- Ο τεχνικός έλεγχος γίνεται αποκλειστικά στο παρασκήνιο και δεν εμφανίζεται στον πελάτη.
- Επιλογή γλώσσας επάνω δεξιά: αλλάζει ολόκληρη την ιστοσελίδα και το τελικό παραδοτέο σε Ελληνικά ή Αγγλικά.
- Αυτόματη παραγωγή απλού παραδοτέου πελάτη και χωριστού εσωτερικού τεχνικού δελτίου.
- Κυπριακό εκπαιδευτικό πλαίσιο μόνο για παιδί ή έφηβο.
- Σύντομη πρακτική έκδοση ενηλίκου χωρίς ενότητες εργασιακού περιβάλλοντος ή σχεδίου 8–12 εβδομάδων.
- Δημιουργία πλήρους εντολής για ChatGPT ή Claude.
- Η πλήρης εγκεκριμένη δεσμευτική εντολή περιλαμβάνεται αυτούσια στην εφαρμογή.
- Αυτόματη επιλογή του σωστού ανώνυμου προτύπου σύντομης έκδοσης για παιδί/έφηβο ή ενήλικα.
- Το καθαρό Word ακολουθεί τη λιτή μορφή GAVRIELA χωρίς πίνακες· οι τεχνικοί πίνακες παραμένουν μόνο στο εσωτερικό δελτίο.
- Έτοιμο δίγλωσσο μήνυμα με κουμπί αντιγραφής για επικόλληση μαζί με το Word της εντολής.
- Προαιρετική απευθείας δημιουργία με προσωπικό OpenAI API key.
- Έλεγχο του τελικού Word και χωριστού τεχνικού δελτίου.

## Εκτέλεση

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/streamlit run app.py
```

Στα Windows χρησιμοποίησε `.venv\\Scripts\\streamlit run app.py` στην τελευταία εντολή.

## Ροή

1. Ανέβασμα PDF και αυτόματος τεχνικός έλεγχος δεδομένων.
2. Επιλογή υπηρεσίας και γλώσσας. Η παρουσίαση είναι πάντοτε απλή και πρακτική.
3. Λήψη εντολής ή αυτόματη δημιουργία.
4. Ανέβασμα και έλεγχος τελικού Word.

Η εφαρμογή αποτελεί εργαλείο συμβολικής αυτογνωσίας και όχι επιστημονικό ή ψυχομετρικό τεστ επαγγελματικού προσανατολισμού.
